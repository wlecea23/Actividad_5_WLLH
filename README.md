# Sistema de Detección de Fraudes en Transacciones  
  
## Objetivo  
  
Desarrollar un modelo de aprendizaje automático capaz de identificar transacciones fraudulentas mediante técnicas de clasificación supervisada.  
##   
## Dataset  
  
Credit Card Fraud Detection https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud  
##   
## Modelos evaluados  
  
* Regresión Logística  
* Random Forest  
##   
## Validación  
  
* Grid Search  
* Cross Validation (k=5)  
##   
## Métricas  
  
* Accuracy  
* Precision  
* Recall  
* F1 Score  
* ROC AUC  
##   
## Seguimiento  
  
MLflow  
##   
## Reproducción  
  
1. Clonar repositorio.  
2. Instalar dependencias.  
3. Ejecutar datos_prep.py.  
4. Ejecutar train.py.  
5. Revisar métricas en MLflow.
